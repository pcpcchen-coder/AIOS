## 2. Differences from delivery design brief

| Item | Brief | Implementation | Reason |
|---|---|---|---|
| Disabled reasons | Browser/camera not enabled/encryption unavailable/model absent or hash wrong/re-enrollment all disable | **Only** browser or encryption unavailable disables Family recognition. Camera/model issues still allow view/delete with limited_reason in sublabel/screen; re-enrollment is screen hint | Deletion must not depend on camera/models, ADR §2.2 |
| Change event | SSE identity.changed with epoch/gallery_version | Existing settings.updated; settings.identity itself carries epoch/gallery_version/count | No new event; menus already update on settings.updated |
| Consistency | Core checks consistency | Each sample cosine to mean ≥0.5 **and** every pair ≥0.4, MATCH_THRESHOLDS | Mean-only admits half one person/half another with ≈0.7 to mean; reproduced in test |
| startNous options | dir/secretBox/excludeFromBackup/confirm | Also modelDir | Core hashes models and serves only validated runtime |
| Sampling cadence | ≤4 Hz | ≤4 Hz checked every 50 ms; next frame as soon as inference returned and 250 ms elapsed | Avoid whole-tick waits accidentally exceeding 500-ms evidence/enrollment gap |
| Slow enrollment | Gap>500 ms discards batch | Same, plus truthful gap N seconds/computer busy message before any samples | Cloud §4.5 otherwise stays zero without explanation |
| Family redraw | Unspecified | No redraw if unchanged | Per-frame DOM replacement removed stop button between down/up, making it unclickable |
| YuNet 640 resize | Spike canvas resize | letterboxToChw OpenCV fixed-point port, one worker readback | Resolves ADR §10 unchecked letterbox; preproc yunet640-cvlinear-bgr-v1 |

Initial thresholds, all uncalibrated: match 0.5, margin 0.08, consistency 0.5, pair 0.4. Quality requires face width≥100 px, box inside frame, score≥0.8, nose horizontal offset≤0.2, pitch 0.2–0.8, roll≤20°, box mean brightness 40–220. Optional sharpness not implemented, pending Mac data.

<a id="5-殘餘風險照實"></a>
## 5. Residual risks

- **Old snapshots decryptable:** safeStorage application key does not rotate. Old gallery.v1.json with wrapped DEK in Time Machine/APFS can theoretically decrypt on same Mac, fixture-reproduced in store test. Time Machine exclusion reduces risk; APFS local snapshots unaffected. UI/delete confirmation disclose.
- **Memory:** base 64 DEK/decrypted JSON strings remain in V 8 heap, not proactively zeroable. Zeroable buffers/features are cleared.
- **Probing remains after review:** session page can send three-plus same-face frames to infer enrollment through stable matched/unknown; duplicate enrollment also reveals possibly enrolled, inherent to probing. Mitigations: user menu click,15min/navigation expiry,6/sec,no scores,≥3 frames,duplicate no name.
- **Rollback:** replacing gallery with older file unprotected, possibly resurrecting deleted person; prewrite revision prevents two-core overwrite only.
- **Tampered wrapped key** becomes key_unavailable with retry/Keychain/restart instruction; retry cannot fix tampering but data is not cleared/overwritten.
- **Photos/screens:** no liveness/spoof defense; identity is greeting-only, never authorization.
- **Cloud numbers:** one thread unloaded; three people cosine.
- **SFace training-data terms** unresolved, ADR §9.
