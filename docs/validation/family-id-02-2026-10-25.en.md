## 3. Design details

<a id="31-時序辨識不延長面向等待"></a>
### 3.1 Timing: recognition never extends facing wait

```
在場確認(500 ms) → 面向確認(300 ms) → 停留(設定秒數 − 0.3 s) → startTalk（原時間）→ 語音連線 → 就緒 → 600 ms → 問候決策 → 送出
                                   └─ 同步取樣（停留期間＋連線期間，≤4 Hz）────────────────────────────┘
```

The diagram shows presence 500 ms→facing 300 ms→dwell(setting minus 0.3 s)→original startTalk→connection→ready→600 ms→decision→send, with concurrent≤4 Hz sampling during dwell/connection.

SenseController.tick first decides startTalk by original rules, then reports snapshot. Recognition cannot delay/block startup. Cold models/no frame→no_evidence, ordinary I'm here.

<a id="32-問候前的-6-個條件14-3由誰檢查"></a>
### 3.2 Ownership of six pre-greeting conditions, 14 §3

| Condition | Page eligible | Core |
|---|---|---|
| Same interaction/generation | Same ID/bound generation=current | Last-frame generation=bound |
| Single person | No multi-face in generation | No multi-face/two family members |
| Still near/facing/fresh | Presence/near/facing/camera ok | ≥3 frames/≥500ms/latest≤1sec/quality |
| Person still exists/gallery unchanged | — | Matchable; gallery changes clear evidence/pending text |
| Switches on/not sent | Read greet-first before/after take | Naming still on/once per ID |
| No speech/typing/collapse/camera-off/end | Speech/type/collapse/end→skipped,no greeting; camera-off increments generation,no name | Camera-off no name |

Failed name conditions remove name but still say I'm here. Cancellation conditions remove greeting entirely.

<a id="33-姓名出現在哪裡"></a>
### 3.3 Where names appear

ADR §2.4.1 table. Core composes; **key instructions briefly cross renderer** from IPC to response.create, while live page handles interaction ID only. Both model transcripts show subtitles, as user already hears them. New logs omit name/person_id/scores. After speech, names may follow conversation: plan delegation attaches recent transcript to Codex; model may put name in persisted local JSON task title and send it to task engine. Thus only greeting itself is one short sentence, not that all cloud data is limited to it.
