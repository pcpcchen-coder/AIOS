# 對話音量 VOL-1（2026-11-07）

George 2026-11-07 要求：對話的音量要能用語音控制，可以調 eMeet 或直接調系統音量。

## 做了什麼

- **調的是 Nous 說話的聲音。** 頁面播放 AI 語音的元素（兩條即時語音路徑共用）照「對話音量」設 `volume`：100 等於系統音量，10 是最小。
  - 不改系統音量，也不改 eMeet 本身的音量。網頁沒辦法改 Pi 的系統音量；要改得在 Pi 套件加本機服務，這批沒做。
  - 不碰收音、喚醒、提示音與聲納提示。
- **用說的。** 即時語音的新工具 `set_voice_volume`，兩條路徑都有：
  - API key 路徑：模型直接呼叫。
  - ChatGPT 方案路徑：語音層交辦，工具執行層呼叫，頁面執行。
  - 參數：`change`（`up`／`down` 一次 20，`reset` 回 100），或 `level`（10–100）；給了 `level` 就以 `level` 為準。
  - 結果是 `confirmed` 加上真實的 `volume`，同時顯示字幕「對話音量：N」。
  - 被夾到上限或下限時帶 `note`。到最大時說要更大聲請調系統或喇叭；到最小時說不會完全靜音。
- **分清楚家電。** 沒有指名設備的「大聲一點」「小聲一點」「音量 60」都是 Nous 的聲音。說了設備名稱（例如「電視大聲一點」）才交給 `home_control`。
  - 原本家電規則裡的例句「大聲一點」改成「電視大聲一點」。
  - 沒有接中控時，規則不提家電工具。
- **每台裝置各自記住。** 值存在頁面的 `localStorage`（`nous.voice-volume.v1`），Mac 主視窗與 Pi 終端機各一份，不送核心。
  - 讀不懂的值或儲存被封鎖時用 100。
  - 保存失敗只影響下次開啟，這次照設定播放。
- **設定頁。** 新增「這台裝置的對話音量」：「目前 N」加上「小聲一點／大聲一點／恢復預設」三個按鈕，和語音指令是同一個設定。
  - 到上限或下限時對應的按鈕停用。
  - 瀏覽器版與 App 版都有，中英文都有。
- 語音指令表（README 中英文）新增一列。

## 已知限制

- **最大就是系統音量。** 要比現在更大聲，先把 Pi 的系統音量（eMeet）調到最大一次，之後用說的在這個範圍裡調。
- **ChatGPT 方案路徑調音量也是一次交辦。** 會用到 Codex 額度，也比 API key 路徑慢一點。
- **只在即時語音中能用說的調。** 「語音模式」的系統朗讀不受這個設定影響。

## 還沒驗證

- 沒有在 Mac 或 Pi 實機上試過語音調音量。
- 待驗：
  1. 在 Pi 說「你講話小聲一點」，下一句回覆變小聲，字幕顯示「對話音量：80」。
  2. 說「音量 40」再說「大聲一點」，變成 60。
  3. 重新載入頁面後仍是 60。
  4. 說「電視大聲一點」時是按電視的遙控鍵，不是調 Nous。
  5. Mac 的音量不受 Pi 影響。
