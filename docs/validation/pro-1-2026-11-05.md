# 主動提醒 PRO-1：招呼後說今天天氣驗證

日期：2026-11-05（Asia/Taipei）。分支：`claude/pro-1-weather-briefing`（基於 main `ce1489c`）。

**沒有在 Mac 上執行過，也沒有連過真的 Open-Meteo。** 以下是 Linux 雲端的假時鐘與假 Open-Meteo 回應（fixture）測試。

## 1. 做了什麼

每人每天早上第一次打招呼時，Nous 在招呼句後面接一句今天的天氣，例如：

> 早安，George。今天台北多雲，22 到 28 度，下午降雨機率 60%，記得帶傘

- **核心決定要說什麼**：天氣那一句是確定性的模板（`shared/proactive.ts` 的 `weatherSentence`），資料來自核心自己的快取；模型只照念，和原本的招呼句一樣放在 `「」` 裡。
- **兩條語音路徑都支援**：API key 路徑放在 `response.create` 的嚴格版指示裡（`strictGreetingInstructions`）；ChatGPT 方案路徑放在 sideband 的 `session.context.append`（每段 ≤500 bytes，原本的切段）。
- **live → API key 切換不重複說**：頁面的 `GreetingOnce` 整次對話只打一次招呼；核心另外只在問候真的送出時才記下「今天說過」，之後再決策一次也不會再說天氣。
- **沒有新增語音或頁面送內容的入口**：頁面仍然只送互動 ID。

## 3. 規則細節

1. **什麼時候接天氣**：總開關與天氣開關都開、本機時間在時段內、有地點、快取裡有今天的天氣、這個對象今天還沒說過。
2. **對象**：問候稱名的家人 → `person:<id>`（說了同時記 `device`）；沒認出或沒稱名 → `device`。所以 George 先聽過，之後沒認出的人不會再聽一次；沒認出的人先聽過，George 被認出時仍會聽到自己的那次。
3. **什麼時候算說過**：API key 路徑是核心把指示交回頁面時；ChatGPT 方案路徑是 sideband 真的取用招呼時。使用者先開口（F10）讓招呼被丟掉時不算。
4. **瀏覽器版**：ChatGPT 方案路徑的保底招呼（沒有家人決策）也會接天氣（裝置規則）；API key 路徑在瀏覽器版由頁面自己組「我在」，不經核心，所以**瀏覽器版 API key 路徑不會說天氣**。

## 6. 沒有驗證的項目

- 模型會不會照念整段（尤其 API key 路徑曾改句，見 ID-02 F1）、念天氣時會不會加字或漏掉數字。
- 真的 Open-Meteo 回覆與延遲；預先取天氣是否來得及在第一次招呼前回來（看著說話約 1.5 秒＋連線＋600 ms）。
- 念長一點的招呼對「先開口」判斷（F2、F10）的影響。
- 城市座標是市府附近的近似值。

## 7. Mac 實測步驟

1. 拉 main、重新建置 App。選單列「鏡頭與語音設定」→「主動提醒」應看到：總開關（開）、說今天的天氣（開）、時段 5–11 點、天氣地點「依系統時區（台北）」、狀態「天氣：還沒查過」。
2. 早上 5–11 點看著螢幕（或說 Hello Nous）開始通話：聽到「早安，George。今天台北…度…」。記下：有沒有念完、有沒有改字、從招呼開始到念完幾秒。
3. 結束後再開一次：只打招呼，沒有天氣。
4. 換另一位家人（或不看鏡頭、讓 Nous 認不出）：認出的家人會聽到自己的那次；認不出的人今天不再聽。
5. 選單列把地點改成「高雄」，隔天早上確認念的是高雄。
6. 關掉 Wi-Fi 後重開 App、隔天早上第一次招呼：只打招呼、狀態顯示查詢失敗。
7. 把總開關關掉：回到只打招呼。
8. 有開 `NOUS_AIL=on`、`NOUS_AIL_SERVICES` 加 `weather` 時，問「今天天氣如何？」：模型呼叫 `app.weather.today` 回答。
9. 看 `~/.config/nous/proactive-log.json`：只有日期與 `device`／`person:fam_…`。

## 8. 回退

- 使用者端：選單列或設定頁把「早上招呼後主動提醒」關掉，立即回到只打招呼（不需要重啟）。
- 程式：revert 這個 PR；`proactive.json`、`proactive-log.json` 可以直接刪掉。

## 9. 下一批（PRO-2）規劃草案

1. **行事曆詢問**：只有認出的人是行事曆擁有者（CAL-1 帳號對應的家人，可設定，預設 George）時，在天氣後問「要不要我念今天的行程？」。
2. **是／否**：沿用記憶的 YES/NO 白名單、只在問句念完之後算（`readyAt`）、逐字稿回音不算；說好才經 CAL-1 讀今天行程並念重點；說不要或沒回答就不念、今天不再問。
3. **電子腦**：真的讀行程、真的念時，依 `domain: "planning"` 點亮規劃區。
4. **之後**：沒有通話時主動開口（定時晨報、行程前提醒）另開一批；需要先決定什麼時候可以自己發聲、音量與誰在場。
