# WK-00 wake word Mac trial record (2026-10-31)

Run on the Mac per [WK-00 §7](wk-00-spike-2026-10-29.en.md) and the [Mac acceptance runbook](mac-acceptance-runbook-2026-10-30.en.md) §9, to settle the keyword and threshold that [17 §14.1](../17_Wake_Word_and_Speaker_Recognition_Plan_2026-10.en.md) D1 was waiting for. Only George took part this round (code A), and **only the trial part of steps 1–3 was done**; other family members' pronunciations, the 30-attempt positives, the 8-hour TV negative and CPU alongside the camera (full step 3, steps 4 and 5) are still to do.

Conclusion: neither model could recognise George saying the Chinese "哈囉努斯"; George decided to switch to the English **Hello Nous**. Configured in zh-en-3M with ARPAbet, George's voice hit 7/10 live and 9/10 offline, and saying only "Hello" never triggered. The setting is written into `shared/wake-runtime.json` (`configured`).

## Findings

- **F1: several `listen` processes running together overwrite each other's reports.** The report name is only a millisecond timestamp (`wk00-plain-<ms>.json`), so processes that end together write the same file. The two rounds in row 5 lost 1 and 3 reports. Not fixed.
- **F2: the event JSON's `threshold` / `boost` show the engine defaults, not the keyword file's.** With `--keywords-file`, the per-line `:` / `#` values are not reflected in events. Not fixed.
- **F3: the CLI's cue is easy to miss.** "Trial n/5" is a single line of text, and George could not see it outside the terminal panel. A chime, a full-width colour block and press-Enter-to-start were added afterwards (a scratch script, not in the repo), and all 13 later attempts were spoken on time. If family members are to run WK-00 step 3 themselves, the CLI should get a similar cue.
- **F4: the Chinese candidate does not suit the current models.** Both models are open-vocabulary KWS; synthetic speech hits with relaxed settings, but George's natural, fast "哈囉努斯" (0.6–1.1 s per utterance) barely registers, with a single hit even when slowed to 0.75×. This matches the WK-00 cloud result of 0/300 synthetic positives.
- **F5: threshold and false wakes need more checking.** `0.15` is looser than the engine default `0.25`. The six "Hello"-only attempts (3 offline, 3 live) never triggered, but the 8-hour TV negative (W6) has not been run.
