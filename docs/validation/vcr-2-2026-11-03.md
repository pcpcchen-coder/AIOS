## 3. 設定頁「語音中繼（實驗）」

只在設定頁打開、且核心回報 `voice_relay: true` 時讀取與顯示；不在背景輪詢、不是 Dashboard。

- 開頭：模式（「Mac 喇叭實際發聲」或「模擬：不會發出聲音」）、「播放成功只代表聲音已送出，不代表音箱照做。」、「沒有回音抑制：Nous 自己的麥克風可能聽到這些播放。」；目標或燈的清單變更後提示要重新啟動。
- 輸出：聲音與喇叭數量、「重新讀取聲音與喇叭」。
- 「新增 Google Home Mini」：語系（zh-TW／en-US）、喇叭、聲音（依語系過濾）、音樂服務（選 Spotify 或「不知道」會擋所有音樂命令）。fake 模式下另提示「新增後會取代示範目標。」
- 每個目標：啟用／停用；聲線清單（試聽用聲線、語速、音量、停頓、前後靜音、「儲存聲線」、「新增候選聲線」）。修改模型正在用的聲線會清掉這個目標所有「已採用」，要重新採用。
- 每個意圖的每個說法：文字、喚醒詞、狀態（已採用／候選／已拒絕／政策封鎖）；必要的參數欄位；「預覽文字」「測試喚醒」「測試整句」「採用這組」／「取消採用」。政策封鎖的說法不能播放或採用。每個意圖只會有一個已採用的說法。
- 測試整句且回報「已發出、未確認」後，才出現紀錄區：有沒有喚醒、命令正確／錯誤／沒有執行、證據（目視／人工確認），「記錄結果」。摘要顯示「喚醒 a/b、命令 c/d、整體 e/f」，分母 0 顯示 N/A，沒有資料顯示「未測試」。
- 播放只來自「測試喚醒」「測試整句」兩個按鈕；結果從不說「成功」。

## 4. HTTP 路由

| 路由 | 內容 |
|---|---|
| `GET /api/voice-relay` | 畫面資料 `VoiceRelayView` |
| `POST /api/voice-relay/refresh` | 重讀聲音與喇叭 |
| `POST /api/voice-relay/preview` | 唯讀預覽（可指定候選說法與聲線），不播放 |
| `POST /api/voice-relay/play` | `part: "wake"｜"full"`；使用者在畫面上明確選的候選可以試播；20 秒時限；結果永遠不是 `confirmed` |
| `POST /api/voice-relay/target`、`/profile`、`/adopt`、`/unadopt`、`/trial`、`/enabled` | 修改設定或新增測試紀錄，回傳新的畫面資料 |

和其他設定路由一樣只經 localhost／Origin／JSON 檢查，沒有額外登入；請求上限 16 KB。

## 5. 模型路徑

- 工具仍是 `app.voice_relay.send_intent`（VCR-0）。`mac` 模式說明不帶「（模擬）」，播完回「已發出語音命令，但執行結果尚未確認。」。
- 只有「已採用」（目標的 `reviewedTemplates` 為 approved）且是解析器預設會選的說法才會播；候選、已拒絕、政策封鎖一律拒絕。測試以真 HTTP 伺服器確認：未採用 → `not_reviewed`；採用後 → `unconfirmed`；取消採用 → 又拒絕。
- 結果對應：`say` 結束代碼 0 → `unconfirmed`；啟動後非 0 → `unknown`；無法啟動 → `failed`；喇叭或聲音不存在 → `failed`（沒有啟動 `say`）；逾時或中止 → `unknown`，不重試。`say` 結束代碼 0 代表它把聲音送進指定裝置並播完，不是硬體回執。

## 7. 未驗證項目

- **在 Mac 上實際執行**：`say -v ?`／`say -a ?` 的真實輸出格式、`-a` 指定喇叭、`[[volm]]`／`[[slnc]]` 是否生效、結束代碼與實際播完的關係。
- Google Home Mini 對任何說法與聲線的辨識率（NOT TESTED）。
- 回音：依決定不處理，Nous 通話中自己的麥克風可能把「Ok Google…」當成使用者說的話。
- 打字聊天與背景任務不能用這個工具（只有兩條即時語音路徑）。
- 新增或移除目標、燈之後，模型工具清單要重新啟動 Nous 才更新。
- Electron App 內的畫面沒有在 Mac 上看過。

## 8. 回退方案

- `NOUS_VCR=off`（預設）或從 `NOUS_AIL_SERVICES` 拿掉 `voice_relay`：沒有這一段、沒有路由、模型沒有工具。
- 在畫面上「停用」目標或「取消採用」：只停那台音箱或那個說法。
- 刪除 `<NOUS_CONFIG_DIR>/voice-relay/` 資料夾：回到沒有目標的狀態。
- 設定檔錯誤只會讓 `voice_relay` 不啟用或不能存，不影響 HomeBridge、其他整合與語音對話。

## 9. 怎麼用（Mac）

1. `.env` 加上：`NOUS_AIL=on`、`NOUS_AIL_SERVICES=voice_relay`、`NOUS_VCR=mac`，重新啟動 Nous。
2. 打開設定頁 →「語音中繼（實驗）」→「新增 Google Home Mini」：選語系（和音箱的語言設定一樣）、要發聲的喇叭、聲音、音樂服務。新增後重新啟動 Nous 一次。
3. 在每個要用的意圖上按「測試喚醒」「測試整句」，聽音箱的反應，填紀錄；調整語速或停頓再試。
4. 滿意的那組按「採用這組」。之後在語音通話對 Nous 說「叫 Google 下一首」之類的話，模型就會用這組說法與聲線實播；Nous 只會說「已發出語音命令，結果尚未確認」。
