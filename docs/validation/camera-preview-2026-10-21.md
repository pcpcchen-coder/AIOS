# 鏡頭預覽小視窗與鏡頭設定驗證

日期為 2026-10-21，平台為 Linux 雲端環境，Node.js 22.22.0，Chromium 無頭瀏覽器。這是原型的驗證，沒有變更 G0 至 G3 驗收狀態。

## 瀏覽器實測（合成影像，非實機）

Chromium 以 `--use-file-for-fake-video-capture` 播放一段自製的 2560×720 併排影像：左右兩半各有一個亮圓（近物，左右錯開 60 px）與一個方塊（遠物，錯開 8 px），亮圓左右擺動。鏡頭名稱用 `NOUS_CAMERA_LABEL=stereo.y4m` 指向這段影像，MediaPipe 模型由 `npm run vision:setup` 下載後實際載入執行。**這不是 AR0144 實機影像**，畫面裡也沒有人，所以只驗證影像流程與畫面，不驗證偵測準確度。

| 操作 | 觀察 |
| --- | --- |
| 啟動 | 指示點變綠，`data-state="ok"`。 |
| 輸入「顯示鏡頭畫面」 | 指示點上方出現兩個小視窗，`data-visibility-reason="user_request"` 並帶本次請求 id。 |
| 即時影像（左眼） | 顯示左半畫面：亮圓與方塊。 |
| 左右眼差異 | 近物亮圓呈現寬的新月形雙邊，遠物方塊只剩兩條細邊，背景全黑，符合預期的視差。 |
| 另開一次新的頁面（預覽收起）→ 點指示點 | 預覽開啟。這一列是獨立的新頁面，不是接在上面語音開啟之後。 |
| 「鏡頭設定」→ 面向螢幕秒數按兩次 + → 看著說話按一次 | `camera.json` 變成 `look_to_talk_s: 1.7`、`look_to_talk: false`，畫面上的開關變成「關」。 |
| 「鏡頭關掉」→ 重新整理頁面 | 指示點保持隱藏，鏡頭沒有被重新打開。 |
| 「打開鏡頭」 | 指示點回到綠色。 |
