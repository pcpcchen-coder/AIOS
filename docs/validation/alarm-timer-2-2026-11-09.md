# 鬧鐘 ALARM-2（2026-11-09）

George 2026-11-09 要求的第二批：鬧鐘（單次與重複、貪睡、錯過處理、設定頁管理）。建立在 [ALARM-1 定時器與響鈴框架](alarm-timer-1-2026-11-09.md)（#133，已合併 main `671826d`）上，分支 `claude/alarm-clock`。

**證據層級：** 只有 Linux 雲端的單元／整合測試與無頭 Chromium（假時鐘、模擬即時語音、模擬頁面）。**Mac 與 Pi 實機都沒有執行**（第 6 節）。

## 1. 沿用的 George 決定

ALARM-1 的「較溫和」預設全部沿用（只在設定的那台響、30 秒漸強、5 分鐘自動停止、通話中只靜音 Nous、Mac 防睡＋30 分鐘內補響）。本批另外用到的預設：貪睡 9 分鐘；鬧鐘最低音量 30%（定時器沒有最低音量）；時區沿用 #96 的本機（系統）時區。

## 2. 設計

- **資料：** `alarms.json` 升到版本 2，多了 `alarms`（鬧鐘）、`snoozes`（貪睡中）與 `time_zone`；版本 1（ALARM-1）的檔案照讀，下次寫入時升級。鬧鐘存牆上時間（`hour`、`minute`），重複只存星期幾（0＝星期日），單次存當地日期；`next_at` 是核心算好的下一次（epoch）。最多 20 個鬧鐘。
- **本機時間：** `shared/alarm-schedule.ts` 用時區把當地日期與時間換成 epoch。夏令時間開始時不存在的時間（例如美東 02:30）延到跳過之後的同一個相對位置（03:30）；夏令時間結束時重複的時間用第一次。時區改變（`time_zone` 和現在不同）時，每個開著的鬧鐘重算下一次。
- **響過之後：** 單次鬧鐘自動關掉（保留，可以再打開）；重複的算「現在之後」的下一次，所以睡了好幾天也只補一次（或只記一次錯過）。錯過與晚響規則和定時器相同（30 分鐘內照響並說晚了多久）。
- **貪睡：** 只有鬧鐘有。響鈴畫面的「貪睡 9 分鐘」、打字或通話中整句說「貪睡」「再睡一下」，或模型呼叫 `app.alarm.snooze`。貪睡會停下這個頁面所有的鈴（同時在響的定時器一起停），9 分鐘後在同一台再響；右下角按需顯示「貪睡 8:59」倒數（`data-visibility-reason="alarm_snoozed"`）。關掉或刪除鬧鐘會一併取消它的貪睡。
- **按需倒數：** 一小時內要響的鬧鐘在右下角顯示「07:00 42:10」（`alarm_soon`）；不是鬧鐘清單。清單只在設定頁。
- **音量：** 鬧鐘的最後音量＝max(這台裝置現在的對話音量, 30%)。
- **Mac 防睡：** 12 小時內有鬧鐘、或有貪睡時也阻止閒置睡眠；AlarmCenter 每次檢查都重算，所以晚上設的早上鬧鐘會在 12 小時前開始防睡。
- **系統通知：** 鬧鐘的通知標題是「鬧鐘：『起床』」。

### 2.1 工具（兩條即時語音路徑共用，核心內建）

| 工具 | 作用 |
|---|---|
| `app.alarm.set` | `time`（24 小時制本機時間）、`repeat`（once、daily、weekdays、weekends、custom）、`days`（custom 用，例如 `mon,wed,fri` 或「一三五」）、`date`（單次的日期，不給就是下一次的這個時間）、`label` |
| `app.alarm.list` | 鬧鐘（時間、重複、開或關、下一次）與貪睡中的 |
| `app.alarm.enable` | 打開或關掉（不刪除）；打開過期的單次鬧鐘時改成下一次的這個時間 |
| `app.alarm.delete` | 刪除一個或全部 |
| `app.alarm.snooze` | 貪睡 |
| `app.alarm.stop_ringing` | 停止；`cancel_snoozes` 一併取消貪睡（「不用再叫我了」） |

找鬧鐘可以用名字、時間（「6:30」）或 ID；有好幾個而沒說是哪一個時回 `refused` 加 `data.candidates`。兩條路徑的指示本來就有今天日期與時區（`todayLine`），說話規則 `ALARM_RULE` 要模型把「明天」「下週三」換成 `date`，上午下午有疑問時先問。

### 2.2 設定頁

「鬧鐘與定時器」一段新增「鬧鐘」清單：每一個有時間、名字、重複、下一次（用核心的時區顯示）、開關與刪除；下方可以新增（時間、單次／每天／工作日／週末、名字）。指定星期的重複用說的設定。清單只在設定頁，不是常駐畫面。

## 3. 語音指令表

`shared/voice-commands.ts` 的段落改名「定時器與鬧鐘」，加上兩列鬧鐘說法；「定時器或鬧鐘響鈴時」加上貪睡。README 由 `npm run docs:commands` 產生，英文 README 同步翻譯。

| 可以這樣說 | 結果 |
|---|---|
| 「明天早上 7 點叫我」「每個工作天 6:30 叫我」「週一三五晚上 9 點提醒我倒垃圾」 | 設定鬧鐘 |
| 「有哪些鬧鐘」「關掉明天的鬧鐘」「刪掉 6:30 的鬧鐘」 | 列出、開關、刪除 |
| 鬧鐘響時：「貪睡」「再睡一下」 | 本機比對（`matchRingSnooze`），9 分鐘後再響 |
| 鬧鐘響時：「停」「我起來了」 | 本機比對，停止 |

## 5. 已知限制

- ALARM-1 的限制都還在：手動睡眠或蓋上時核心停住；Pi 響不響要看 Mac；響鈴期間喚醒詞暫停，沒有通話時不能用說的停止或貪睡；通話中鈴聲會進麥克風。
- **鬧鐘時間用 Mac 的時區：** Pi 的瀏覽器時區不同也照 Mac 的時區響；設定頁的「下一次」也用 Mac 的時區顯示。
- 防睡只在 12 小時內有鬧鐘時：晚上 7 點以前設好的隔天早上 7 點鬧鐘，Mac 要到晚上 7 點才開始防睡；這之前 Mac 若閒置睡著，醒來的規則照錯過處理。
- 家人稱名（響鈴時說「George，起床了」）本批沒有做：響鈴時沒有在辨識，要做需要另外設計（建議之後再評估）。
- API key 路徑字幕的工具訊息：帶時間或名字的句子在英文介面仍是中文（同 ALARM-1）。

## 6. 回退與在家實測

**回退：** 同 ALARM-1：設定頁「鬧鐘與定時器」關掉（工具消失、不排程不響，鬧鐘保留）；「清除全部」刪掉定時器、鬧鐘、貪睡與紀錄；或刪掉 `<configDir>/alarms.json`。revert 這個 PR 後，版本 2 的 `alarms.json` 舊版讀不懂，會改名成 `alarms.json.unreadable` 並從空的開始（定時器也會清掉）。

**在家實測：**

1. 更新 Mac App，Pi 頁面重新整理。設定頁「鬧鐘與定時器」→「鬧鐘」確認是空的。
2. 在 **Pi** 用說的設一個兩分鐘後的鬧鐘：例如現在 21:10，就說「21:12 叫我」。確認 Nous 說已設定、設定頁出現這個鬧鐘、下一次是今天 21:12；一小時內所以右下角出現倒數。
3. 到點：Pi 響、畫面是「鬧鐘」、有「貪睡 9 分鐘」。按貪睡：右下角出現「貪睡 9:00」。9 分鐘後再響，這次說「我起來了」（通話中）或按「停止」。
4. 說「每個工作天 6:30 叫我」「週一三五晚上 9 點提醒我倒垃圾」，問「有哪些鬧鐘」；在設定頁關掉其中一個、刪掉另一個。
5. 夜間把對話音量調到最小（10），確認鬧鐘仍至少 30% 的音量（定時器則照 10%）。
6. 睡眠：設一個 10 分鐘後的鬧鐘，讓 Mac 睡 15 分鐘再叫醒：醒來幾秒內響，寫「晚了 5 分鐘」。
7. 隔天早上確認工作日鬧鐘真的在 6:30 響（只在設定它的那台）。
