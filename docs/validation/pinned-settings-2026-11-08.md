# 設定畫面釘在最上層、字放大 1.5 倍（2026-11-08）

George 2026-11-08 回報：點右下角齒輪打開的設定畫面，有時會自己收起來，像是電子腦要回到畫面中。他要求：

1. 設定畫面一直留在最上層，只有點「收起」才關；
2. 設定畫面的文字放大 1.5 倍。

## 為什麼會自己收起

查程式找到幾個會收起任何畫面的來源。Pi 上最可能的是：

- **鏡頭判斷人離開了**：在場判斷連續 60 秒看不到人，就收起畫面並結束即時語音。
- **喚醒詞或開始即時語音**：開始一通語音前會先收起畫面。
- 其他：Esc、說「收起」、送出打字聊天、別的畫面（進度、成果）出現。

還沒在 Pi 上確認當時是哪一個；下面的修改把這些來源全部擋住。

## 做了什麼

- **釘住**：`src/shell-state.ts` 新增純函式 `keepPinnedSettings`。使用者打開設定畫面後，其他事件仍照常更新任務、收音與語音狀態，但畫面換回同一張設定卡（同一個 `surface_id`，不重畫）。
- **怎麼關**：只有設定畫面底部的「收起」按鈕或右下角的齒輪會解除釘住（`closeSettings`，main.ts 裡唯一清除釘住的地方）。Esc、說「收起」、人離開、喚醒詞、開始語音都不會關。
- **確認卡例外**：外部動作（例如需要確認的家電指令）的確認卡可以暫時蓋在設定上；確認卡結束後回到設定畫面。如果連確認卡也擋住，會等到逾時被當成拒絕。
- **字放大 1.5 倍**：設定畫面用 `zoom: 1.5`，字、按鈕與間距一起放大。外框加寬到螢幕寬度（最多 1200 px）；高度上限除以 1.5，放大後仍在螢幕內、可以捲動。只影響設定畫面，其他畫面不變。

## 測試

- `tests/pinned-settings.test.ts`（6 項）：
  - 收起事件留在同一張設定卡；
  - 進度畫面不會取代設定，任務狀態照樣更新；
  - 確認卡可以暫時蓋上，結束後回到設定；
  - 解除釘住後行為跟以前一樣；
  - main.ts 只有 `closeSettings` 會解除釘住；
  - CSS 的 1.5 倍與高度上限。
- **無頭 Chromium（mock 核心，Pi 頁面 1920×1080 與 1024×600）：**
  - 點齒輪打開設定，標題字級 20 px × zoom 1.5；
  - 1920×1080 外框 1200×780，1024×600 外框 983×425，都在螢幕內；
  - 按 Esc 不會關，點畫面下方也不會關；
  - 按「收起」會關；再點齒輪會打開，再點一次會關；
  - 頁面沒有 JS 錯誤。
- `npm run typecheck`、`npx vitest run`（165 個檔案，3051 項通過、5 項略過）、`npm run build`、`node scripts/verify-aios.mjs` 都通過。

## 已知限制

- 1024×600 這種小螢幕上，設定畫面放大後一次看得到的內容較少，要往下捲。
- 右下角齒輪會蓋到設定卡右下角一小塊；捲動後就能點到被蓋住的按鈕。
- 沒有在 Pi 實機確認。
