WK-00 喚醒詞 spike / Wake-word spike

開發工具，不是產品功能。麥克風音訊只在本頁記憶體（2 秒環形緩衝），不錄音、不寫檔、不連外。KWS 需要自建的 sherpa-onnx wasm（放在 spike/wake/public/kws-wasm/），npm 套件沒有瀏覽器版。
Developer tool, not a product feature. Microphone audio stays in this page's memory (2-second ring buffer); nothing is recorded, saved or sent. KWS needs a self-built sherpa-onnx wasm in spike/wake/public/kws-wasm/; the npm package has no browser build.
